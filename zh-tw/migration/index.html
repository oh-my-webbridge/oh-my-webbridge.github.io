遷移到 oh-my-webbridge

把 Kimi 瀏覽器擴充功能、MCP 瀏覽器伺服器、瀏覽器 CLI 與 Playwright 或 Puppeteer 指令碼的指令對應到 oh-my-webbridge 的動作。

技術預覽

omw 目前是技術預覽版，正在快速迭代。之後的版本一定會有破壞相容性的變更。

oh-my-webbridge 的每個指令都指定一個工作階段、一個動作，以及一個參數 JSON 物件。本頁的表格把其他工具的常用指令對應到這些動作。搬移任務之前，請先在與其他工具比較中確認 oh-my-webbridge 沒有提供的功能。

開始之前

  1. 安裝 daemon 與擴充功能，並配對瀏覽器。請見快速開始。
  2. 以 omw install-skill ~/.agents/skills 安裝 Agent 技能。關閉原本工具的技能或 MCP 伺服器，讓 Agent 在一項任務中只使用一個工具。
  3. 執行 omw status。它為每個瀏覽器印出一行，例如 chrome: connected (156.0.8078.80)。

所有工具共通的變更

  • 工作階段。 每項任務使用一個工作階段名稱，例如 checkout。第一個指令會開啟工作階段，它的分頁在背景開啟，並放進同一個分頁群組。任務結束時送出 close_session。所有工作階段都使用你的瀏覽器設定檔與其中的 cookie。
  • 參照。 參照的格式為 @e<generation>.<index>，來自該分頁最新一次的 snapshot。以 @e 開頭、來自其他工具或較舊快照的參照會以 stale_ref 失敗。不帶 @ 的參照（例如 e12）會被當成 CSS 選擇器。導覽之後請重新取得快照。
  • 定位器。 selector 參數接受 CSS 與文字定位器，Playwright 定位器可以對應到這些形式。role= 完全比對名稱，而 getByRole 在未設定 exact: true 時比對子字串。串接的定位器與 .filter() 沒有對應形式。請見選擇器。
Playwright 定位器oh-my-webbridge 選擇器
getByRole("button", { name: "Submit", exact: true })role=button[name="Submit"]
getByText("Sign in")text=Sign in
getByLabel("Email")label=Email
getByPlaceholder("Search")placeholder=Search
getByTestId("search")testid=search
.first()、.last() >>nth=0、 >>nth=-1
  • JavaScript。 evaluate 接受運算式，而不是函式。請送出 document.title，或把函式包成呼叫：(() => document.title)()。使用 await 的程式碼放進非同步函式呼叫：(async () => (await fetch("/api")).status)()。
  • 檔案。 screenshot 與 save_as_pdf 接受絕對路徑 path 並傳回它，不會覆寫已存在的檔案。
  • 期限。 指令預設在 30 秒後失敗。HTTP 請求本文的 timeoutMs 欄位，或 omw call 的 --timeout-ms，可設定 1 到 120000 毫秒。時間用盡的 wait 會以 wait_timeout 失敗。
  • Firefox。 部分動作在 Firefox 中回應 unsupported。請見 Firefox。

從 Playwright 或 Puppeteer 指令碼遷移

在擴充功能模式下，daemon 在 /json/list 列出頁面目標，並在 /devtools/page/{tabId} 提供單一分頁。它的 /json/version 沒有 webSocketDebuggerUrl。Playwright 的 chromium.connectOverCDP 與 Puppeteer 帶 browserURL 的 puppeteer.connect 會讀取這個欄位來找到瀏覽器端點（Playwright 原始碼、Puppeteer 原始碼）。這類指令碼有兩種搬移方式。

讓指令碼使用原生模式

原生模式透過 daemon 轉送瀏覽器端點。以 --remote-debugging-port=9222 與另一個 --user-data-dir 啟動 Chrome，再以 http://127.0.0.1:9222/json/version 中的瀏覽器 URL 啟動 daemon：

Playwright 在 headers 中帶上 token 連線，寫法請見 CDP。Puppeteer 則傳入 browserURL: "http://127.0.0.1:17373"，並在 wsOptions.headers 中帶上同一個標頭。這樣指令碼操作的是那個另外啟動的 Chrome，而不是你平常使用的設定檔。

把指令碼改用 SDK

SDK 透過擴充功能操作你使用的瀏覽器中的分頁。
